# Collapsing Mini Galaxy — Hand Gesture Control

This project is an interactive, real-time simulation of a glowing, filament-style mini galaxy that you can control with your hands using your webcam. It uses computer vision and hand tracking to let you rotate and zoom the galaxy with simple gestures.

---

## What is this project about?

- **Visual:** A dense, tangled, glowing galaxy core with purple, green, and white filaments, inspired by real astronomical images.
- **Interaction:**
  - **Left hand:** Move your index finger left/right to rotate the galaxy (spin).
  - **Right hand:** Pinch/spread your thumb and index finger to zoom in/out (scale).
- **Technology:** Uses OpenCV for video, MediaPipe for hand tracking, and NumPy for math/array operations.

---

## How to run or fork this project

1. **Clone or fork the repository:**
   - Click the "Fork" button on GitHub, or clone with:
     ```
     git clone <repo-url>
     ```
2. **Install dependencies:**
   - Open a terminal in the project folder and run:
     ```
     pip install opencv-python mediapipe numpy
     ```
3. **Run the project:**
   - Start the simulation with:
     ```
     python "Galaxy hands.py"
     ```
4. **Enjoy!**
   - Use your webcam and hand gestures to control the galaxy.
